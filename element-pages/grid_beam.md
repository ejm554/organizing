## Related: BeamCNC

- An open-source add-on for a router that claims to improve the task of making accurate Grid Beam elements.
- Sources appear to be circa 2017, so the following images and web pages might be useful for historical reference only.
- Designer: Vladislav lunachev
- [Designer's page on Core77](https://www.core77.com/projects/69637/BeamCNC-Works-with-Common-Materials-to-Help-Produce-Grid-Beam-Projects)
    - Includes photos of the tool and Grid Beam creations, and screenshots of furniture from an online catalog
- [Hackaday article](https://hackaday.com/2017/09/27/beamcnc-computer-controlled-construction-system-mill/)
