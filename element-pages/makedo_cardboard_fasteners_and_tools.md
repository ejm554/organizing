# MakeDo

- Proprietary toy system for manipulating and fastening found cardboard.
- Includes perforating tool (for folding), saws, screws, hinges, etc.
- 3D-printing community has models for their own versions of the screws.

Links:
- Official MakeDo Tools: https://www.make.do/collections/tools
- Example open-source screw: https://www.thingiverse.com/thing:3867969/remixes
    - Also compatible with LEGO Technic
